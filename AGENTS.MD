Project Goals:

1. Reimplement Code Property Graph's Schema in Native Rust.

2. Create a custom Json Schema Dialect around Code Property Graph using jsonschema crate.

3. Ensure that the file hierarchy, module hierarchy, and object model, struct and trait and type hierarchy to match the original scala implementation while being implemented idiomatic Rust.

4. Use Context Generic Programming (CGP) and derive-deftly Rust metaprogramming framework to decouple and organize project: https://github.com/contextgeneric/cgp.git, https://gitlab.torproject.org/Diziet/rust-derive-deftly

Target Project Repo: https://github.com/QuasarRay/CPGSchema.git

Original Project Repo: https://github.com/ShiftLeftSecurity/codepropertygraph.git
