# MetaData — compile-time CPG JSON Schema dialect/vocabulary

This bundle converts the standalone `MetaData.rs` builder model into a static
JSON Schema resource compiled during `cargo build`.

## Files

- `src/MetaData.rs`
  - `MetaData` marker implementing `SchemaBase`
  - `MetaDataValidator` generated by `#[jsonschema::validator]`
  - custom dialect, Base dependency, vocabulary and custom keywords supplied at compile time
- `src/CpgVocabulary.rs`
  - annotation-style custom keyword implementation shared by CPG modules
- `schemas/cpg-dialect.schema.json`
  - extended CPG Draft 2020-12 dialect/meta-schema
- `schemas/base.schema.json`
  - Base resource, included because MetaData depends on Base.VERSION and Base.HASH
- `schemas/metadata.schema.json`
  - declarative MetaData schema
- `build.rs`
  - build-time meta-validation of Base and MetaData against the CPG dialect
- `Cargo.toml.snippet`

## Semantics preserved

`OVERLAYS`:
- FlatGraph value type: String (`cpg:valueType = "String"`)
- cardinality: list
- JSON representation: array of strings
- symbolic ProtoId: `Overlays`

`LANGUAGE` and `ROOT`:
- String
- mandatory
- default `<empty>`

`META_DATA` property order:
1. local `LANGUAGE`
2. `Base.VERSION`
3. local `OVERLAYS`
4. `Base.HASH`
5. local `ROOT`

`Languages` remains an ordered constant category with all 20 constants.
The removed Solidity proto ID 16 note is retained as `$comment`.

## Compile-time behavior

Two build-time layers are used:

1. `build.rs` validates the schema documents themselves against the CPG
   dialect meta-schema. Invalid CPG keyword shapes fail `cargo build`.
2. `#[jsonschema::validator]` compiles `metadata.schema.json` into specialized
   Rust validation code. The custom dialect and Base resource are supplied as
   compile-time resources; there is no runtime `Registry` or `.build(...)`.

Add to `lib.rs`:

```rust
pub mod SchemaBase;
pub mod CpgVocabulary;
pub mod MetaData;
```
